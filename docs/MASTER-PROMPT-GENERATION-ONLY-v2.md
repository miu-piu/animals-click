# «Зверята 2.0» — мастер-промпт для генерации исходных фотографий

При генерации одной карточки инструмент получает описание только текущего животного.

## ЗАДАНИЕ ИСПОЛНИТЕЛЮ

Ты создаёшь **все 141 новых реалистичных изображений животных** для детского Android-приложения «Зверята 2.0», начиная **с первого нового животного по каталогу**. Соблюдай точный порядок, выполняй работу без согласования после каждой десятки и без обсуждения каждого шага с пользователем.

Репозиторий: `miu-piu/animals-click`; рабочая ветка: `feature/zveryata-v2`.

Сначала прочитай файлы:
1. `catalog/catalog-v2.json` — точные виды, подписи, возраст, сцены и порядок 142 записей.
2. `catalog/batches-v2.json` — производственные десятки.
3. `catalog/image-production-state-v2.json` — рабочий журнал прогресса.
4. `docs/TZ-images-v2.md` — требования к содержанию и визуальная проверка.
5. `docs/IMAGEGEN-CLEAN-PROMPT-v2.md` — **единственный шаблон для самого генератора**.
6. `scripts/make_generation_briefs_v2.py` — видовые уточнения (не передавай весь скрипт генератору).

### Старт

- Запись **001** имеет статус `skipped`: просто пропусти без генерации и без отдельного обсуждения.
- **Первое создаваемое изображение — 002 `cat` («кошка»)**. Затем 003 `kitten`, 004 `dog` и далее по порядку до 142.
- Прогресс определяется исключительно журналом `catalog/image-production-state-v2.json` и физически сохранёнными, проверенными оригиналами. При возобновлении пропускай только действительно готовые карточки.

### Генерация

1. Планировщик берёт одну следующую запись из каталога, подставляет её `reference`, `stage`, `scene` и индивидуальные видовые требования в короткий позитивный шаблон `docs/IMAGEGEN-CLEAN-PROMPT-v2.md`.
2. **В сам инструмент генерации передаётся исключительно итоговое описание ОДНОГО конкретного животного и одной сцены**. Никакого текста о проекте, партиях, журналах и технической подготовке. Не прикладывай изображения других животных как визуальные референсы.
3. Создавай отдельную **вертикальную фотографию 9:16**. Животное одно, целиком, с правильной анатомией и возрастом, на спокойном натуральном фоне. Тело и видоспецифичные черты должны быть ясно различимы ребёнком с первого взгляда.
4. Внутри агента просмотри получившийся кадр. Если он соответствует виду, возрасту, анатомии и формату цельной фотографии — сохрани исходник. Если не соответствует — попробуй исправить предметное описание; после повторяющейся структурной ошибки перейди на независимую сессию генерации, если она технически доступна, иначе честно пометь блокировку. Не зацикливайся на одном виде.
5. **Сразу сохраняй каждый удачный оригинал**, без изменений изображения, с точным ID, контрольной суммой SHA-256 и реальным путём в доступном хранилище. Обновляй `catalog/image-production-state-v2.json` после каждой карточки (или другой явно сопоставимый сохранённый журнал, если запись в GitHub временно недоступна). Не заявляй, что файл в GitHub, если фактически записан только локально.
6. Переходи к следующему ID самостоятельно. Внутренние группы по 10 служат только для прогресса — **не требуй подтверждения десятки**. Проходи весь каталог до последней записи, затем повторно пробуй только пропуски, используя доступный независимый режим.

### Только первый этап — оригинальные изображения

**СЕЙЧАС НЕ ДЕЛАЙ:** APK, изменение кода приложения, WebP-конвертацию всей коллекции, обзорные листы 2×5, ZIP между десятками, новый каталог или изменение существующих ТЗ.

**РЕЗУЛЬТАТ ПЕРВОГО ЭТАПА:** 141 отдельный новый исходник, у каждого точный `id`, исходный SHA-256, сохранённый файл и статус проверки. Только **ПОСЛЕ** полного прохода перейти к следующему отдельному этапу: углублённая визуальная приёмка, адресные исправления, WebP 1440×2560, программные обзоры, ZIP и Android-интеграция.

**Важное техническое ограничение:** одно сообщение обычного чата не обеспечивает безлимитную длительность исполнения. Если инструмент или сеанс заканчивается, сохрани сделанное и точный следующий ID, скажи, что действительно завершено. Не обещай невидимую фоновую работу.

**НАЧИНАЙ С 002 — КОШКА.** Не составляй повторное ТЗ, не проси подтверждения, выполняй доступную генерацию и продолжай по порядку.
