# Зверята 2.0 — исходные изображения

В этой папке хранятся неизменённые исходники, а в `assets-v2/approved/webp` — отдельные оптимизированные файлы, которые прошли визуальную приёмку.

- `legacy-ari.webp`: исходный файл карточки Ари прежней версии, SHA-256 `05d8c4828dc9a5c1ff9f8ccd412701e0629cd38bd804d6b80dff3134fc61675e`. Сохранён без редактирования. Подлинность как пользовательской фотографии отдельно не установлена; нельзя считать генерацию подтверждением личности собаки.
- Для новых изображений сохранять исходные PNG/JPEG рядом, отдельно от WebP.
- Финальная сборка проверяет SHA-256 каждого оригинала, SHA-256 готового WebP и наличие записи о фактической визуальной приёмке.

Нельзя удалять оригиналы после конвертации или отмечать изображение утверждённым только по результату проверки формата файла.
