# Зверята — Android

Отдельный Android-репозиторий для нативной версии детского приложения «Зверята».

Источник логики и визуальных ассетов: `miu-piu/kids-games/animals-click`.

Цель: нативное Android-приложение на Kotlin + Jetpack Compose, полностью офлайн, с полноэкранной галереей животных, свайпами в 4 стороны, автоматическим переходом через 30 секунд и совместимостью со штатным Android Screen Pinning.
