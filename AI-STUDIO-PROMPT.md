# Зверята 2.0 — инструкция для AI Studio (нативное Android-приложение)

**Версия: 2.0. Этот файл относится только к разработке Android, не к генерации фотографий.**

Используй этот репозиторий как **существующий Kotlin + Jetpack Compose проект** `com.miupiu.zveryata`. Не создавай React/Next.js, PWA или новый проект. Сохрани прежний package ID и название лаунчера **«Зверята»**. Работай в `feature/zveryata-v2`, не затрагивая `main` и архивную ветку.

**Нормативные документы в порядке применения:**

1. [`docs/TZ-v2.md`](docs/TZ-v2.md) — требования к приложению, взаимодействию, экрану, памяти, тестированию, сборке.
2. [`catalog/catalog-v2.json`](catalog/catalog-v2.json) — 142 карточки, точные ID, подписи и порядок.
3. [`docs/TZ-images-v2.md`](docs/TZ-images-v2.md) — критерии подготовки изображений; не замена ТЗ приложения.
4. [`README.md`](README.md) — фактическое состояние кода, тестовых и релизных сборок.

## Android-поведение 2.0

- **Одна** реалистичная фотография и русское название на экране.
- Чёрная верхняя шапка `#000000`; название `#F2F2F2`, системный sans-serif Medium, **32 sp базово**, строго по центру доступной области шапки. Фотография ниже без рамок, до боковых и нижней границ.
- Пропорции фото сохраняются. Полное тело должно оставаться видимым; для других пропорций экрана адаптировать природный фон, не растягивать животное и не обрезать важные части тела.
- **Влево/вверх — следующая; вправо/вниз — предыдущая.** Чёткий порог **56 dp** и коэффициент преобладания оси **1,6**; неопределённые диагонали не переключают.
- **Тапы, удержание и случайные микродвижения ничего не переключают.** Отдельное отслеживание пальцев; максимум один переход за принятый жест.
- Защита от повторных ручных переключений **3000 мс**. Первый свайп с момента открытия доступен сразу.
- **Автосмена через 30 секунд** после показа карточки или завершённого перехода; пауза при сворачивании, новый полный интервал при возвращении.
- Автономный APK без сетевой загрузки картинок, рекламы, регистрации, трекинга и ненужных разрешений.
- Использовать штатное Android/Samsung Screen Pinning, не имитировать kiosk-mode; fullscreen не гарантирует защиту от выхода.
- Сохранять существующую утверждённую иконку. Фотографию первой карточки не создавать нейросетью и не менять без отдельного решения.

## Сборки и контент

На этапе проверки приложения используется временный preview-каталог; **финальный релиз должен содержать все 142 утверждённые карточки** из `catalog/catalog-v2.json`. Финальные WebP **1440×2560** принимаются только после завершения отдельного этапа генерации и визуальной проверки. Не заменяй контент приложения произвольными фотографиями и не объявляй preview релизом.

Используй `scripts/package_content_v2.py --mode release` для проверки утверждённой коллекции; он должен останавливаться, если не хватает хотя бы одной карточки. Подписанный релиз: `.github/workflows/release-v2.yml`; ключи подписи не помещать в GitHub.

Перед выпуском нужны автоматические тесты навигации, таймера, каталога, интерфейса и сборки, плюс реальная проверка на целевом телефоне. Отмечай только **фактически** выполненные проверки.

**Если исходники и эта краткая инструкция расходятся с `docs/TZ-v2.md`, нормативным документом является `docs/TZ-v2.md`.**
